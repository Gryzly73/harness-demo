# Паспорт проекта для агента

> Русский перевод корневого `AGENTS.md`. Рабочей инструкцией для Cursor Agent
> остаётся корневой файл.

- Проект: Python-библиотека `minisearch`.
- Python: 3.10 или новее.
- Runtime-зависимости: только стандартная библиотека.
- Установка: `pip install -e ".[dev]"`.
- Общая проверка: `make check` — Ruff, pytest и английский recall.
- Проверка текущей задачи: поле `done when` в `PLAN.md`.
- Правила workflow: `.cursor/rules/`.
- Защищённые пути: перечислены в `SPEC.md`.
