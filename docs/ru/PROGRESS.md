# Журнал прогресса

> Русский перевод шаблона `PROGRESS.md`. Harness и агент записывают фактическое
> состояние в корневой файл.

Это журнал решений и динамического перепланирования. На каждое событие агент
добавляет одну строку; Harness читает журнал при следующей итерации.

Пример:

```text
iter 1 T1: реализованы ядро, CLI и английская оценка
iter 2 REPLAN T2: перед persistence требуется стабильное хеширование
```
