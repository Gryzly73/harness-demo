# Команда `/next-task`: одна итерация loop

Вы выполняете одну итерацию автономного цикла разработки.

Прочитайте в следующем порядке:

1. `SPEC.md`;
2. `PLAN.md`;
3. `PROGRESS.md`;
4. `.loop/last_failure.txt`, если файл существует.

После этого выполните только указанную текущую задачу, соблюдая правила:

```text
.cursor/rules/workflow.mdc
.cursor/rules/replanning.mdc
```

Если предыдущая попытка завершилась неудачно, причина находится в
`.loop/last_failure.txt`. До изменения кода определите корневую причину.

Если причина находится за пределами текущей задачи, добавьте необходимую
подзадачу вместо обходного изменения.
