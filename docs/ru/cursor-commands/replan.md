# Команда `/replan`: уточнение плана

Сопоставьте `PLAN.md` со `SPEC.md`, последними записями `PROGRESS.md` и
`.loop/last_failure.txt`.

Добавьте отсутствующие подзадачи, но не удаляйте и не изменяйте существующие.
Каждая новая подзадача должна иметь собственную команду `done when`.

Причину каждого изменения запишите одной строкой в `PROGRESS.md`.

На этом этапе не изменяйте код продукта.
