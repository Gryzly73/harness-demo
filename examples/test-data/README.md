# Пример тестовых данных minisearch

Набор имитирует небольшую корпоративную базу знаний и не изменяет защищённые
данные Harness в корневых `data/` и `eval/`.

## Состав

```text
examples/test-data/
├── corpus.jsonl    16 документов: 8 русских и 8 английских
├── eval_ru.jsonl   8 русских контрольных запросов
├── eval_en.jsonl   8 английских контрольных запросов
└── README.md
```

Темы документов:

- отпуск и больничный;
- пароль и удалённый доступ;
- техническая поддержка;
- командировочные расходы;
- гостевой пропуск;
- фишинговые письма.

## Формат корпуса

Одна строка — один UTF-8 JSON-объект:

```json
{"id":"ru-it-vpn","text":"Для удалённого доступа...","lang":"ru"}
```

Обязательные поля:

- `id` — уникальный стабильный идентификатор;
- `text` — непустой текст документа;
- `lang` — `ru` или `en`.

## Формат контрольных запросов

```json
{"query":"удалённый доступ через VPN","relevant":["ru-it-vpn"]}
```

`relevant` может содержать несколько допустимых документов. Запрос считается
успешным, если хотя бы один ожидаемый идентификатор попал в первые `k`
результатов.

## Ручная проверка поиска

Команды выполняются в функциональной ветке `loop/1008-130105` после установки
проекта.

Построить индекс:

```powershell
python -m minisearch.cli index `
  --corpus examples/test-data/corpus.jsonl `
  --out examples/test-data/index.json
```

Русский запрос:

```powershell
python -m minisearch.cli search "как подключить удалённый доступ" `
  --index examples/test-data/index.json `
  --lang ru `
  -k 3
```

Английский запрос:

```powershell
python -m minisearch.cli search "report a suspicious email" `
  --index examples/test-data/index.json `
  --lang en `
  -k 3
```

## Автоматическая оценка

Вспомогательный script `examples/evaluate_sample.py` принимает произвольные
пути, поэтому не требуется заменять штатные `data/` и `eval/`.

Русский набор:

```powershell
python examples/evaluate_sample.py `
  --corpus examples/test-data/corpus.jsonl `
  --queries examples/test-data/eval_ru.jsonl `
  --lang ru `
  --min-recall 0.9
```

Английский набор:

```powershell
python examples/evaluate_sample.py `
  --corpus examples/test-data/corpus.jsonl `
  --queries examples/test-data/eval_en.jsonl `
  --lang en `
  --min-recall 0.8
```

Для каждого запроса выводятся `PASS` или `FAIL`, ожидаемые документы, найденные
идентификаторы и итоговый `recall@3`.

## Как заменить данные своими

1. Скопируйте `corpus.jsonl`.
2. Замените документы, сохранив формат и уникальность `id`.
3. Составьте реальные пользовательские запросы.
4. Для каждого запроса вручную укажите корректные `relevant`.
5. Не используйте один и тот же текст запроса и документа: набор должен
   проверять поиск, а не точное копирование.
6. Проверяйте русский и английский наборы отдельно.
7. Просматривайте отдельные `FAIL`, даже если общий порог достигнут.

Файлы индекса, сформированные во время проверки, не являются исходными тестовыми
данными и не должны добавляться в Git.
