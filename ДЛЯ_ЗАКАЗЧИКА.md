# minisearch — локальный поиск по текстовым документам

## Назначение

`minisearch` — компактное поисковое ядро для небольших наборов русских и
английских документов. Оно подходит для внутренних инструкций, FAQ, регламентов,
заметок и каталогов. Поиск выполняется локально: документы и запросы не
передаются во внешние сервисы.

В этом репозитории поисковик одновременно является целевым продуктом и примером,
на котором демонстрируется управляемая разработка с AI-агентом.

## Возможности готовой версии

- загрузка документов из JSONL;
- построение индекса и ранжирование по cosine similarity;
- сохранение и повторная загрузка индекса;
- русский и английский поиск;
- фильтрация результатов по языку;
- выгрузка результатов в JSON и CSV;
- интерфейс командной строки и Python API;
- работа без внешней базы данных, модели и runtime-зависимостей.

## Исходные данные

Корпус — UTF-8 JSONL-файл, одна запись на строку:

```json
{"id":"vacation","text":"Порядок оформления ежегодного отпуска","lang":"ru"}
{"id":"deployment","text":"Application deployment instructions","lang":"en"}
```

Поля:

- `id` — уникальный идентификатор;
- `text` — текст документа;
- `lang` — `ru` или `en`.

## Пользовательский сценарий

### 1. Подготовка документов

Заказчик выгружает документы из своей информационной системы в JSONL. Каждый
документ должен иметь стабильный уникальный идентификатор, текст и язык. Файл
можно обновлять по расписанию или формировать перед очередной индексацией.

### 2. Построение индекса

Поисковик читает корпус, нормализует текст, преобразует документы в числовые
векторы и сохраняет индекс в JSON-файл. Операция выполняется после изменения
корпуса, а не перед каждым пользовательским запросом.

### 3. Выполнение запросов

Готовый индекс загружается из файла. Пользователь передаёт текст запроса,
необходимое число результатов и, при необходимости, ограничение по языку.
Система возвращает документы от наиболее подходящего к наименее подходящему.

## Использование

Установка на Windows:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

Построение индекса:

```powershell
python -m minisearch.cli index --corpus data/corpus.jsonl --out index.json
```

Поиск:

```powershell
python -m minisearch.cli search "как оформить отпуск" `
  --index index.json --lang ru -k 3
```

Результат содержит идентификатор, оценку соответствия и начало документа.

Пример результата:

```text
vacation	0.816	Порядок оформления ежегодного отпуска
sick-leave	0.204	Инструкция по оформлению больничного
```

Без `--lang` поиск выполняется по всему корпусу. Для ограничения доступны:

```powershell
--lang ru
--lang en
```

## Выгрузка результатов

Текстовый вывод остаётся форматом по умолчанию. Для интеграции или последующего
анализа выдачу можно сохранить в UTF-8 JSON:

```powershell
python -m minisearch.cli search "как оформить отпуск" `
  --index index.json `
  --lang ru `
  -k 10 `
  --format json `
  --output results.json
```

Либо в CSV, который можно открыть в Excel:

```powershell
python -m minisearch.cli search "как оформить отпуск" `
  --index index.json `
  --lang ru `
  -k 10 `
  --format csv `
  --output results.csv
```

Оба структурированных формата содержат:

- `id` — идентификатор документа;
- `score` — оценку соответствия;
- `text` — полный текст документа;
- `lang` — язык документа.

Если `--output` не указан, JSON или CSV выводится в консоль. Нативный XLSX не
создаётся, поскольку проект не использует внешние runtime-библиотеки; CSV
корректно импортируется Excel и другими табличными программами.

Python API:

```python
from minisearch import HashingEmbedder, Index

index = Index.load("index.json", HashingEmbedder())
results = index.search("как оформить отпуск", k=3, lang="ru")
```

На базе Python API можно создать REST-сервис, веб-интерфейс, Telegram-бот,
поиск в корпоративном портале или интеграцию с существующей системой.

## Как работает поиск

Текст приводится к нижнему регистру и разбивается на токены. Для русского языка
нормализуется `ё`, а словоформы упрощаются стеммингом. Hashing-преобразование
строит вектор фиксированной длины, после чего документы ранжируются по косинусной
близости к запросу.

Это лексический поиск с нормализацией, а не нейросетевая семантическая модель. Он
хорошо находит совпадающие и близкие словоформы, но не гарантирует понимание
синонимов без общих слов.

## Обработка русского языка

Для русскоязычных запросов выполняются:

- распознавание кириллицы;
- приведение к нижнему регистру;
- замена `ё` на `е`;
- упрощённое приведение словоформ к общей основе.

Например, запрос с формой `оформить отпуск` может найти документ, содержащий
`оформление отпуска`.

## Варианты применения

- корпоративные инструкции и регламенты;
- база знаний службы поддержки;
- HR-документы;
- техническая документация;
- локальные заметки;
- небольшой товарный каталог;
- офлайн-поиск в изолированной сети.

## Эксплуатационные требования

- Python 3.10 или новее;
- внешние runtime-зависимости отсутствуют;
- интернет для пользовательского поиска не требуется;
- внешняя база данных не требуется;
- индекс хранится в обычном JSON-файле;
- корпус должен помещаться в оперативную память.

## Подтверждённое качество

Реальный контрольный прогон Cursor Agent создал поисковик с нуля и получил:

- 15 успешно пройденных тестов;
- Ruff без ошибок;
- `recall@3` для английского — `1.000` при требовании `0.800`;
- `recall@3` для русского — `1.000` при требовании `0.900`.

Готовая функциональная версия сохранена в ветке
[`loop/1008-130105`](https://github.com/Gryzly73/harness-demo/tree/loop/1008-130105).

## Ограничения

Текущая реализация рассчитана на небольшие корпуса, помещающиеся в память. Для
миллионов документов, сложной семантики и высокой нагрузки потребуются
специализированный индекс, embedding-модель и сервисный API.

## Результат

Заказчик получает готовое локальное поисковое ядро, которое можно запускать из
командной строки либо встраивать в прикладную систему. В отличие от заранее
подготовленного решения, эта версия была создана Cursor Agent с пустого
`src/minisearch/`, после чего независимо проверена Harness по защищённым тестам
и метрикам качества.
